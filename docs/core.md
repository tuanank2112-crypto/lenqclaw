## Đồ thị runtime (D28)

Hai đồ thị, hình = hằng `graph/shape.ts` (`PIPELINE_SHAPE`/`TURN_SHAPE`) = sơ đồ người dùng đã duyệt ([00-ARCH §4](../planning/02_2026-10-09_zalo-community-agent/specs/00-ARCHITECTURE.md)); `graph-shape.test.ts` so `getGraph()` với hằng. KHÔNG checkpointer/Store/`interrupt`/ChatModel/LangSmith (BB-17; `LANGSMITH_TRACING`/`LANGCHAIN_TRACING_V2` bật ⇒ `ConfigError`).

```text
pipelineGraph (1 inbound_events = 1 invoke, recursionLimit 10)
  START ┄► ingest | group_event | system_event | dm_intake
  ingest ┄► triage | END · dm_intake ┄► triage | END · triage ┄► moderate (nhóm) | turn (DM)
  moderate ┄► gate | END · gate ┄► turn | defer | END · system_event ┄► turn | END
  group_event → END · defer → END · turn → END          (turn = runTurn ⇒ turnGraph)
turnGraph (1 lượt, recursionLimit 2×MAX_TOOL_ROUNDS+11)
  START → prepare ┄► agent | deliver · agent ┄► tools | nudge | deliver
  tools → agent · nudge → agent · deliver → trace → END
```

Mọi cạnh điều kiện + `decideDelivery` (12 dòng D1–D12) + `hostText` là hàm THUẦN ở `graph/edges.ts` (không I/O, không `Date.now()`).
